คำแนะนำการนำไปโฮสต์บน GitHub Pages
  1. สร้าง Repository ใหม่ใน GitHub (เช่น ชื่อ public-health-dashboard)
  2. สร้างไฟล์ชื่อ index.html ใน Root directory แล้วคัดลอกโค้ดไฟล์นี้ทั้งหมดลงไป
  3. ไปที่เมนู Settings > Pages เลือก Branch เป็น main หรือ master แล้วกด Save
  4. ระบบจะสร้าง URL เว็บไซต์พร้อมใช้งานทันที (เช่น https://yourusername.github.io/public-health-dashboard/)
